# Autoencoder Implementation Using MNIST Dataset

This project focuses on implementing a simple Autoencoder using Python, TensorFlow, and Keras with the MNIST handwritten digit dataset. An Autoencoder is a type of neural network used for dimensionality reduction, feature extraction, data compression, and image reconstruction. In this project, the MNIST dataset containing 60,000 training images and 10,000 testing images is loaded and preprocessed by normalizing pixel values between 0 and 1 and flattening each 28 × 28 image into a 784-dimensional vector. The autoencoder consists of three main components: Encoder, Latent Representation, and Decoder. The encoder compresses the input data from 784 dimensions into a lower-dimensional representation of 32 features, while the decoder reconstructs the original image from the compressed representation. The model is built using Dense layers with ReLU and Sigmoid activation functions and trained using the Adam optimizer and Binary Crossentropy loss function for 10 epochs. Training and validation loss are visualized using Matplotlib to evaluate the model performance. The encoder is used to extract latent features, and the decoder reconstructs the original handwritten digit images. Original and reconstructed images are displayed side by side for comparison. PCA is also used to visualize the latent representations in two dimensions. This project helps in understanding the working of autoencoders, dimensionality reduction, feature learning, and image reconstruction. The model is successfully trained and evaluated using reconstruction loss and visual comparison.
